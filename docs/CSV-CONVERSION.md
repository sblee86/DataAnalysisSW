# CSV 변환 저장 모드와 상세 로그

PCAP → CSV 변환 화면에서 입력 PCAP, 해석 인터페이스, 메시지를 선택합니다. admin은 모든 ICD를 변환하며 guest는 허용된 ICD만 변환합니다. 저장 위치 설정은 각 Windows 사용자의 개인 설정이며 시험 PCAP 기록 경로와 별개입니다.

## 수동/자동 저장

- 자동 파일명 체크 해제: 기존 Windows 파일 저장 창에서 경로와 CSV 이름을 선택합니다. 선택한 폴더를 다음 기본 경로로 기억합니다.
- 자동 파일명 체크: 저장 창 없이 지정한 경로에 `인터페이스명_yyyyMMdd_HHmmss.csv`로 저장합니다. 시간은 변환 시작 시 PC의 로컬 시간입니다.
- 경로를 직접 입력한 뒤 경로 저장을 누르거나 폴더 선택·변경으로 위치를 바꿉니다. 자동 파일명·날짜 폴더 옵션도 다음 실행에 유지됩니다.
- 날짜·시분초 하위 폴더 생성 체크: 기본 폴더 아래 `yyyyMMdd_HHmmss` 폴더를 만든 뒤 CSV와 로그를 함께 저장합니다. 수동 모드에서는 저장 창에서 고른 폴더 아래에 날짜 폴더를 적용합니다.
- 같은 초에 파일/폴더가 겹치면 자동 모드는 `_001`, `_002` 순번을 붙입니다. 자동 출력은 기존 CSV를 덮어쓰지 않습니다. 수동 모드의 기존 CSV 교체는 저장 창의 확인을 따릅니다.

예시:

```text
D:\DRAS\CSV\20261107_153045\
  인터페이스A_20261107_153045.csv
  인터페이스A_20261107_153045.conversion.log.txt
```

## 변환 로그

CSV 옆에 UTF-8 텍스트 로그를 자동 생성합니다. 같은 CSV 이름으로 재시도해도 이전 로그는 덮어쓰지 않고 로그 파일명에 순번을 붙입니다. 변환 결과 화면의 경로를 확인하거나 변환 로그 열기를 누르세요.

각 로그 줄에는 UTC 기록 시간, 수준, 오류/처리 코드와 JSON 상세 정보가 있습니다. 시작 시 PC 로컬 시각, 입력 PCAP, 출력 CSV, 인터페이스·선택 메시지를 남기고 종료 시 전체 프레임·CSV 행·제외·해석 오류 행·범위 이탈 행과 제외 사유별 개수를 집계합니다.

- 패킷 제외: 원본 패킷 번호·UTC 시간, IP/포트, payload 크기, 관측 ID/Length, 기대 길이와 선택 ICD 크기 등을 기록합니다.
- 전송 구조 오류: 비IP/비UDP, 잘린 IP/UDP, UDP 길이 불일치, IPv4 조각, 미지원 IPv6 확장/조각 등을 구분합니다.
- 메시지 검사 오류: EndpointMismatch, TruncatedHeader, UnknownMessageId(이전 ID 매핑 규칙), LengthMismatch, IcdSizeMismatch, AmbiguousMessage, AmbiguousInterface, OtherMessage 등으로 표시합니다. 새로운 구조 매칭 모드에서는 ID 값을 미리 제한하지 않습니다.
- 필드 해석/범위 오류: 필드명, ICD byte/bit 위치와 payload 기준 위치, 길이·타입·endian, raw 비트 HEX, 해석값, 최소·최대, 오류 이유를 기록합니다. NaN/Infinity 같은 해석 실패와 허용 범위 이탈을 구분합니다.
- 취소/실패: Cancelled 또는 Failed, 처리 위치·집계와 예외 종류·메시지·오류 코드·스택을 남깁니다. 미완성 CSV 임시 파일은 정리하며 이전의 완료 CSV는 유지합니다.

기존 CSV의 DecodeError·RangeError 열과 실제 범위 이탈값 보존은 유지됩니다. 로그는 변환 권한이 있는 현재 인터페이스의 해석 정보만 기록하고 다른 제한 ICD의 이름·원본 문서·키는 기록하지 않습니다. 로그도 CSV와 같은 일반 파일로 관리하세요. 권한 검증 실패나 로그 경로 자체에 쓸 수 없는 경우에는 로그 파일을 만들 수 없으며 화면에 오류를 표시합니다. CSV 저장 후 완료 로그만 실패한 경우에는 저장된 CSV와 로그 경로를 유지하고 경고를 표시합니다.

## 웹 미리보기

브라우저는 실제 NIC/PCAP을 처리하지 않습니다. 동일 저장 옵션과 파일명·날짜 폴더 구조를 CSV/로그가 들어 있는 ZIP 샘플로 확인할 수 있습니다. 실제 브라우저 다운로드 위치는 브라우저 설정을 따릅니다. 별도 로그 버튼은 최근 데모 로그 TXT를 내려받습니다. 로그아웃하면 이전 계정의 최근 로그 링크와 결과를 지웁니다.
