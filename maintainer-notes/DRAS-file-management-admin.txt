DRAS 파일 관리 설명서 — 관리자 참고용
====================================

이 문서는 관리자 보관용입니다.
전체 저장소 및 소스 ZIP에만 포함하며, 일반 사용자용 DRAS-win-x64.zip에는 포함하지 않습니다.
프로그램 화면이나 실행 배포의 READ-ME.txt에 이 문서 내용을 추가하지 않습니다.
실제 비밀번호, 암호화 키, 실제 ICD 데이터는 이 문서에 기재하지 않습니다.

1. 기본 저장 위치
-----------------
%LOCALAPPDATA%는 보통 아래 경로입니다.
C:\Users\사용자명\AppData\Local

Windows 실행 창(Win+R)에 아래 경로를 입력하면 해당 폴더로 이동할 수 있습니다.
%LOCALAPPDATA%\LANscope

프로그램 이름은 DRAS이지만 기존 저장 데이터와의 호환성을 위해
내부 설정 폴더 이름 LANscope를 유지합니다.

2. workspace.bin — ICD·공통헤더·프로파일·계정 설정
---------------------------------------------------
경로: %LOCALAPPDATA%\LANscope\workspace.bin

저장 내용:
- 가져온 CSV 및 C/C++ 헤더의 내부 원본 사본과 파일명
- 등록한 공통헤더 타입 정의와 ID/Length 위치·비트 폭·헤더 전체 크기
- 메시지·필드 정의, 최소/최대값, endian·pack·비트 순서
- 프로파일, 송수신 IP, NIC 매칭, 기록 폴더 경로
- guest의 ICD별 CSV 변환 권한
- 변경한 게스트 ID 및 비밀번호 기반 인증 봉투·수신 공개키
- 변경한 관리자 인증 봉투를 연결하는 서명된 식별 정보

저장 방식:
- ICD 원본·파일명, 공통헤더 원본·정의와 기록 규칙은 관리자 키로
  AES-256-GCM 암호화하여 각각의 봉투로 저장합니다.
- 게스트 비밀번호 원문은 저장하지 않습니다. 비밀번호에서 PBKDF2-SHA256으로
  유도한 키를 사용해 게스트 키를 AES-GCM 봉투로 보호합니다.
- 설정 파일 전체는 현재 Windows 사용자 기준 DPAPI로 암호화합니다.
- 관리자 ECDSA 서명을 검증하여 설정 파일의 변조를 확인합니다.
- Windows에서는 LANscope 폴더와 workspace.bin에 숨김 속성을 적용합니다.

공통헤더를 저장하거나 프로파일·계정 설정을 저장할 때 생성/갱신됩니다.
공통헤더는 별도의 평문 .h 파일로 풀어 두지 않고 이 파일 내부에 저장합니다.
설정은 임시 파일에 완전히 기록한 뒤 교체하는 방식으로 저장합니다.
정상 완료 후 임시 .tmp 파일은 정리됩니다.

3. admin-login.bin — 관리자 비밀번호 변경 봉투
------------------------------------------------
경로: %LOCALAPPDATA%\LANscope\admin-login.bin

관리자 비밀번호를 변경하면 생성됩니다.
새 비밀번호로 기존 관리자 키를 복원할 수 있도록 만든 암호화 봉투입니다.
PBKDF2-SHA256(600,000회)으로 키를 유도하고 AES-GCM으로 보호하며,
관리자 서명을 검증합니다. 비밀번호 원문이나 평문 관리자 키는 저장하지 않습니다.
기존 ICD 암호화 키는 유지하므로 비밀번호 변경 후에도 이전 ICD를 읽을 수 있습니다.

변경 도중 admin-login.bin.<식별값>.pending 파일이 같은 폴더에 생길 수 있습니다.
이는 암호화된 복구용 인증 봉투이며, 정상적으로 최종 파일로 이동하면 사라집니다.
변경이 중단되었을 때 임의로 삭제하지 말고 설정 폴더와 함께 보존하세요.
게스트용 별도 로그인 파일은 없으며 게스트 인증 봉투는 workspace.bin 내부에 있습니다.

4. ui-preferences.bin — 화면 설정
---------------------------------
경로: %LOCALAPPDATA%\DRAS\ui-preferences.bin

글자 크기, 메인 창 너비·높이·최대화 여부, ICD 표 높이,
목록 폭과 입력란 배치를 저장합니다.
숨김 바이너리 파일이지만 암호화 파일은 아닙니다.
ICD 원본·계정 비밀번호·암호화 키는 여기에 저장하지 않습니다.

5. 가져오기 원본, PCAP, 내보내기 파일
-------------------------------------
- 사용자가 선택한 원본 .csv/.h/.hpp 파일은 원래 위치에 그대로 남습니다.
  내부 사본을 암호화하는 것이며 원본 파일을 이동·삭제·암호화하지 않습니다.
- PCAP은 사용자가 지정한 기록 폴더의 시험별 하위 폴더에 표준 파일로 저장합니다.
  PCAP 자체는 암호화하지 않습니다.
- 사용자가 직접 내보낸 ICD CSV·C++·ZIP 및 패킷 값 CSV는 일반 파일입니다.
  내부 암호화 저장소와 별개로 관리해야 합니다.
- 가변 설정은 EXE 옆이 아니라 위 Windows 사용자별 데이터 폴더에 저장합니다.
  실행 ZIP을 다시 풀거나 업데이트해도 별도 삭제하지 않으면 이 폴더는 유지됩니다.

6. 백업·복원
-------------
- 기록과 변환을 중지하고 프로그램을 종료한 상태에서 백업합니다.
- %LOCALAPPDATA%\LANscope 폴더 전체를 함께 보존하세요.
  workspace.bin과 admin-login.bin, 남아 있는 관련 .pending 파일을 한 세트로 관리합니다.
- 화면 설정도 필요하면 %LOCALAPPDATA%\DRAS\ui-preferences.bin을 별도로 보존합니다.
- PCAP과 원본 ICD, 사용자가 내보낸 파일은 각 저장 위치에서 별도로 백업합니다.
- DPAPI 보호는 Windows 사용자 환경에 연결됩니다.
  파일만 복사하여 다른 Windows 사용자나 새 PC에서 여는 일반 이동 방식은 지원하지 않습니다.
- .bin 파일을 텍스트 편집기로 수정하지 말고 DRAS 관리자 화면에서 설정을 변경하세요.

7. 배포 구분
-------------
일반 사용자에게 전달: downloads/DRAS-win-x64.zip
관리자/개발자 보관: 전체 저장소 ZIP 또는 downloads/DRAS-source.zip
관리자 참고 문서: maintainer-notes/DRAS-file-management-admin.txt

이 문서는 실행 배포 ZIP에 포함하지 않습니다.

8. CSV 변환 저장 설정 및 로그 (추가)
----------------------------------
개인 변환 저장 옵션:
%LOCALAPPDATA%\DRAS\conversion-preferences.bin
자동 파일명 여부, 날짜·시분초 하위 폴더 여부, CSV 기본 저장 경로를 기억하는
숨김 바이너리입니다. 암호화 파일은 아니며 비밀번호·ICD 원본·키를 저장하지 않습니다.
시험 PCAP 기록 경로 및 관리자 서명 설정과는 별개로, guest도 자기 변환 경로를 정합니다.

변환 로그:
선택한 CSV 결과 폴더에 CSV와 함께 <CSV이름>.conversion.log.txt로 저장합니다.
날짜 폴더 옵션을 사용하면 yyyyMMdd_HHmmss 하위 폴더에 함께 들어갑니다.
로그는 일반 UTF-8 텍스트이며 허용된 인터페이스의 필드·값·범위·오류 정보를 포함합니다.
기존 로그는 덮어쓰지 않고 충돌 시 순번을 붙이며, 취소·실패 시에도 로그를 유지합니다.
로그는 자동 암호화하지 않으므로 CSV 결과와 함께 관리·백업하세요.
